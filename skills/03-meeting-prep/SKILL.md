# Meeting Prep

## Goal

Make the agency person sound prepared without making them read a research report.

## Read first

For an existing client:

- `client-context.md`
- signals from the last 30–45 days
- open/recent `actions.json`
- latest relevant output/review if present
- any agenda or notes supplied by the user

For a prospect, use the latest prospect-intelligence brief.

## Fresh research

Do **not** browse by default if stored intelligence is current.

Use at most 2 fresh searches when:

- the meeting concerns a current market event
- the last scan is stale
- a named competitor/client development happened since the last output

## Output

Create `clients/<slug>/outputs/meeting-prep-YYYY-MM-DD.md`.

Keep it roughly one page.

### Meeting objective
What outcome should the agency seek from this meeting?

### Client/prospect pulse
Maximum 5 bullets: situation, goals, relevant performance/context, relationship issue if known.

### What changed since last time
Only meaningful deltas with sources where external.

### Open actions / commitments
What was promised, decided, proposed, or is still blocked.

### Three things to discuss
For each:

- issue/opportunity
- evidence
- recommended position
- desired decision

### Questions to ask
Maximum 6.

### Watch-outs
Assumptions, unresolved conflict, missing data, or sensitive points.

## Quality gate

The brief should make sense to an account manager who has not been following every detail, but should not restate the entire client history.

## Stop condition

If the brief is longer than needed for a five-minute pre-call read, compress it.
